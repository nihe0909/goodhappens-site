好事发生会收集哪些数据？

iOS 版：完全没有。iOS 版好事发生不会收集任何个人数据、使用情况分析或追踪信息。

Android 版：为保障应用运行安全，Android 版好事发生通过集成的腾讯 Bugly SDK，在您同意隐私政策后收集以下必要信息：

  • 设备标识符（Android ID） — 用于崩溃日志中区分设备，便于问题定位
  • 设备型号 — 用于分析崩溃在不同机型上的分布情况

以上信息仅用于崩溃分析和应用质量改进，不会用于广告投放、用户画像或其他商业用途。

账号与会员服务：只有当您主动点击账号登录时，我们才处理以下信息：

  • 华为账号 OpenID / UnionID — 由华为账号服务返回，用于验证身份、创建或关联好事发生账号。原始标识仅在认证过程中短暂处理，服务端保存的是通过独立密钥生成的不可逆业务账号标识。
  • 一次性 Authorization Code — 仅用于服务端向华为账号服务验证本次登录；不会写入日志或数据库，验证完成后即丢弃。
  • 业务账号与会员状态 — 用于登录状态、会员权益恢复、兑换及账号注销。我们不会通过华为账号登录获取您的手机号、邮箱、通讯录或日记内容。

鸿蒙版：为保障应用运行安全，鸿蒙版好事发生通过集成的腾讯 Bugly SDK，在您同意隐私政策后收集以下必要信息：

  • 设备标识符 — 用于崩溃日志中区分设备，便于问题定位
  • 设备型号 — 用于分析崩溃在不同机型上的分布情况

以上信息仅用于崩溃分析和应用质量改进，不会用于广告投放、用户画像或其他商业用途。

我的数据存储在哪里？

您的日记、照片和大部分设置仅存储在：

  • 您的设备本地 — 数据存储在您 iPhone、iPad、Mac、Android 手机或鸿蒙设备的私有存储空间中。
  • 您的个人 iCloud 账户中（仅 iOS 版，如果开启了同步） — 如果您使用了 iCloud 同步，数据将通过苹果的 CloudKit 服务同步。我们无法访问您的 iCloud 数据。

当您主动登录账号时，业务账号标识和会员状态会保存在好事发生服务器中，用于在同平台设备间恢复会员权益。日记正文和照片不会因此上传。

数据安全与保护措施

我们遵循最小必要原则处理账号与服务数据，并在应用和服务端采取安全措施保护相关信息：

  • 身份鉴别： 数据同步依赖系统级的账户体系进行严格的身份鉴别与权限控制，确保只有您本人可以访问。应用内支持开启生物识别（面容/指纹解锁）或密码解锁作为二次身份鉴别，进一步保护隐私。
  • 数据加密： 您的数据在设备本地采用系统级标准加密存储。在网络传输过程中，均采用 HTTPS 及传输层安全（TLS）协议保护，防止数据在传输过程中被窃听或篡改。
  • 访问控制： 应用程序采用严格的系统沙盒机制运行，仅在您明确授权时才会请求存储、相机等必要权限。所有的数据读取均受到操作系统的严格权限隔离与访问控制限制。
  • 恶意代码防范： 我们的应用程序在发布前均会经过严格的安全扫描和审核，确保不包含任何恶意代码、木马或病毒，并积极进行防篡改保护。
  • 安全审计： 我们会定期对应用程序进行自我安全审计和漏洞排查，确保依赖的第三方 SDK 均更新至符合安全标准的最新版本，及时防范潜在的安全风险。

第三方服务

iOS 版本

iOS 版好事发生使用了以下苹果官方服务：

  • Apple CloudKit / iCloud — 用于在您的设备间同步数据。该服务受苹果公司的隐私政策约束。
  • Apple StoreKit — 用于处理应用内购买。支付信息完全由苹果处理，我们永远无法看到您的支付详情。

Android 版本

Android 版好事发生集成了以下第三方服务：

  • 腾讯 Bugly SDK — 用于崩溃日志收集与分析，帮助我们定位和修复应用异常。该 SDK 将在您同意本隐私政策后，以自动采集方式收集您的设备标识符（Android ID）和设备型号，仅用于崩溃日志分析和问题定位，不会用于广告投放或其他商业用途。
  • 微信开放平台 SDK — 用于微信登录和微信支付功能。当您主动发起微信登录或支付时，该 SDK 会与微信客户端进行通信以完成相应操作。我们不会通过该 SDK 获取您的微信通讯录、聊天记录等私人信息。

鸿蒙版本

鸿蒙版好事发生集成了以下第三方服务：

  • 腾讯 Bugly SDK — 用于崩溃日志收集与分析，帮助我们定位和修复应用异常。该 SDK 将在您同意本隐私政策后，以自动采集方式收集您的设备标识符和设备型号，仅用于崩溃日志分析和问题定位，不会用于广告投放或其他商业用途。
  • 微信开放平台 SDK — 用于微信登录和微信支付功能。当您主动发起微信登录或支付时，该 SDK 会与微信客户端进行通信以完成相应操作。我们不会通过该 SDK 获取您的微信通讯录、聊天记录等私人信息。
  • 华为账号服务（Account Kit） — 用于华为账号登录。当您主动登录时，应用获取一次性授权码并交由服务端验证；华为账号 OpenID / UnionID 仅用于身份鉴别和业务账号关联，不用于广告或用户画像。
  • 华为应用内支付（IAP） — 用于处理应用内购买。支付信息完全由华为处理，我们永远无法看到您的支付详情。

人工智能 (AI) 功能

在好事发生中，部分功能（如「好事星图」）使用了先进的语言模型来处理您的文本。当您主动使用这些 AI 功能时：

  • 您的相关日记文本将被安全传输至我们的第三方 AI 服务商：阶跃星辰 (Moonshot AI) / 阶跃星辰大模型 (Stepfun AI)，仅用于生成您所请求的功能（例如：提取关键词）。
  • 我们仅发送为实现该功能所必须的最少文本，绝对不会发送您的设备 ID 或个人联系方式。
  • 该 AI 服务商仅作为数据处理者。根据其服务条款，您提交的数据绝不会被用于训练他们的底层大模型。

如果您不点击使用这些 AI 相关的处理功能，您的日记文本不会因 AI 功能离开您的设备或 iCloud。账号登录所需的最少身份信息按本政策“账号与会员服务”一节处理。

广告

好事发生没有任何广告，也不会使用任何广告追踪技术或 IDFA（广告主标识符）。

儿童隐私

好事发生不会故意收集 13 岁以下儿童的个人信息。儿童应在监护人指导下使用账号登录、支付或 AI 功能。

照片与相机权限

当您在日记中添加照片时，好事发生可能会请求相机或相册权限。您选择的照片仅保存在您的设备本地（以及 iOS 版的 iCloud 中），永远不会上传到我们的服务器。

通知

只有当您在设置中主动开启时，好事发生才会向您发送本地的写日记提醒。这些通知是由您的设备在本地触发的，不涉及任何外部服务器推送。

数据删除

您可以随时在 App 内删除日记。卸载 App 可移除设备本地数据；如使用 iCloud 同步，可在系统设置中管理 iCloud 数据。已登录用户可在“设置”中提交账号注销并选择是否同时删除本地数据，账号注销完成后服务器将不再保留该业务账号及会员状态。

隐私政策变更

如果我们需要更新本隐私政策，我们将在本页面进行更新并修改上方的"最后更新日期"。由于我们没有您的联系方式，本页面是我们与您沟通政策变更的唯一渠道。
